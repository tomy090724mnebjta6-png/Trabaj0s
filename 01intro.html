BREVE HISTORIA DE HTML

HTML nacio La historia de HTML (HyperText Markup Language) comenzó en 1990, cuando el científico británico Tim Berners-Lee lo creó en el CERN junto con la World Wide Web para facilitar el intercambio de documentos científicos mediante hipervínculos. En sus inicios (1991-1993), el lenguaje contaba con apenas unas 18 etiquetas y no existía un estándar oficial, lo que provocaba que cada navegador interpretara el código de forma diferente. El primer estándar formal llegó en 1995 con HTML 2.0, y poco después el control pasó al consorcio W3C. Con HTML 4.0 (1997), se introdujeron herramientas clave como las hojas de estilo (CSS) para separar el contenido del diseño visual. Tras un intento fallido de endurecer el lenguaje a principios de los 2000 con XHTML, la evolución dio un giro definitivo en 2014 con el lanzamiento de HTML5. Esta versión moderna revolucionó la web al incorporar soporte nativo para audio, video y gráficos interactivos, eliminando la necesidad de complementos externos como Adobe Flash y adaptándose por completo a la era de los dispositivos móviles. Actualmente, HTML se gestiona como un estándar vivo que se actualiza de manera continua.
